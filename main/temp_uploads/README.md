This folder contains images ready to be uploaded to the About page. 

To add the team photo as the featured "About" image:
1. Start the app: npm run dev
2. Go to the About section (http://localhost:3000#about)
3. Click "Add Team Photo" (admin only)
4. Upload the team photo from this folder
5. Click the star icon to set it as the main featured image

The image will be permanently stored in Supabase and displayed as the large featured image at the top of the About section.
